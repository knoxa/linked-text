# Source documents

Information is extracted from historical documents, judgements made, and conclusions drawn.
Independent analyses of the same source may draw different conclusions.

Source documents may contain errors and inaccuracies.
Documents from different sources may give conflicting accounts of the same event.
Judgement and experience is needed in drawing conclusions from historical texts.
These conclusions are presented as derived data models.

It should be possible to trace a data model back to the historical source text from which it ultimately derives.
My [War Diary](https://knoxa.github.io/war-diary/) project contains transcripts of war diaries held by [The National Archives (TNA)](https://www.nationalarchives.gov.uk/),
so I've followed the instructions in the [Citing records in The National Archives](https://www.nationalarchives.gov.uk/help-with-your-research/discovery-help/citing-records-national-archives/) guide, and included
a TNA reference with each transcribed documents.
I can link each derived fact to a transcript, which in turn links back to the source.
